# algorithms
Бинарный поиск значения в отсортрованном списке.

📌 Разница между подходами:
Критерий	    bisect.bisect_left	          Ручной бинарный поиск
Скорость	    Оптимизирован (быстрый)    	  Медленнее (но тоже O(log n))
Читаемость	  Компактный код	              Понятнее для новичков
Гибкость	    Возвращает позицию вставки	  Можно модифицировать
Зависимости	  Требует import bisect	        Чистый Python
